llamafile builder

Pack a GGUF + llamafile runtime into one portable executable — fully offline. ZIP64 · 64KB align · stream-to-disk (low RAM) · optional Akari-AIO UI with asset cache.

1
llamafile binary required
Download from github.com/mozilla-ai/llamafile/releases — the file named llamafile-X.X.X (no extension, ~100 MB). On Windows, rename it to .exe first to verify it works, then use the original here.

2
GGUF model file required
Any .gguf file. Quantized models (Q4_K_M, Q8_0) recommended. File will be 64KB-aligned in the output for GPU mmap compatibility.

3
.args configuration required
One flag per line. The -m value auto-updates when you load a GGUF. Use ... on its own line to allow the user to pass extra args.
.args flag reference ↗

Common flags (one per line): --host 0.0.0.0 expose on LAN · -c 8192 context window · --nobrowser suppress browser (older versions only) · --system-prompt "you are helpful" default system prompt · -ngl 999 GPU offload layers · --port 8080

4
